# SylSwitch

Alt+Tab that works on every compositor. Bind `sylvaris switcher next` to Alt+Tab and `sylvaris switcher prev` to Alt+Shift+Tab.

The first press opens a row of your windows, most recent first, with live previews on Hyprland and app icons elsewhere. Keep Alt held and tap Tab to move, then let go of Alt to jump to the window. The arrows, Enter, a click or Esc work too.

| Key | Default | Meaning |
|---|---|---|
| `switcher.previews` | `true` | live window previews (Hyprland) |
| `switcher.titles` | `true` | window titles under each card |

See [key bindings](../keybinds.md) to set the keys from SylSettings.
